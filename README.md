# HyperionLedgers

Australian Xero-style accounting demo. Harbour and Co sample. Demo only. No commercial. No ATO lodgement.

## Try it

Open **[/demo](/demo)** for the Harbour & Co sample organisation. No sign-up required.

Optional demo accounts stay in the browser (`localStorage`). They are never sent to a server.

This is not a live accounting product: no ads, no pricing upsell, no live bank feeds, and no ATO lodgement.

## Local development

```bash
npm install
npm run dev
```

Then visit [http://localhost:3000](http://localhost:3000) or go straight to `/demo`.
